# Proposed full-Q2 matrix — design only

**Status:** `SUPERSEDED_BY_D086_REFERENCE_AND_ELIGIBILITY_FREEZE`  
The authoritative unexecuted matrix is now
`final_execution_matrix_d086_unexecuted.csv`; this earlier factor-only design is retained
for provenance.

This design carries D-084 forward without changing or rerunning its pilot records, spectra,
host templates, rungs, transform, or verdict. The expansion unit is one eligible physical
epoch pair crossed with the ten rows in `proposed_full_q2_condition_matrix.csv`:

$$N_{\rm proposed\ cells}=N_{\rm locked\ eligible\ pairs}\times
[1\ {\rm no\!-\!op}+3\ H\ {\rm shapes}\times3\ {\rm nonzero\ rungs}].$$

The full object roster is intentionally not populated here. Paper-3 Gold/Silver/Borderline,
negative controls, Gate B, and Gate D remain open, so using the current development pairs as
the “full” denominator would silently redefine Q2.

## Frozen cell semantics

- Only `PAIR_CONSISTENT` cells enter Q2. Spectrum-diagnostic arms remain pilot diagnostics.
- The faint epoch anchors requested added-stellar fraction at 0, 0.1, 0.5, or 0.85 in the
  rest-frame 5080–5130 Å window. Every nonzero pair uses one shared absolute scalar `a` in
  both epochs; the bright realized fraction is measured, not forced to the faint request.
- The accepted XSL transform and 150 km/s pilot LOSVD convention are retained. Fixed
  continuum S/N uses the accepted deterministic uncertainty transformation and creates no
  random noise realization.
- The exact no-op appears once per pair. It has `H=NONE`; it is not replicated three times.
- At every nonzero rung, `XSL_H1`, `XSL_H2`, and `XSL_H3` remain separate factor levels.
  There are no host-shape probabilities, weights, averages, pooled recovery estimates, or
  post-hoc preferred-template selection.
- Cross-survey pairs retain their aperture/calibration stratum. They may enter only if the
  same physical added-host amplitude is well-defined across the pair under a separately
  frozen calibration treatment; otherwise that Q2 cell is ineligible, not independently
  normalized by epoch.

## Classifier and denominator layout

Every cell produces criterion-specific rows with `analysis_role`. Only
`FINAL_CLASSIFIER` rows enter CL/non-CL/unclassifiable denominators. Guo quick-screen and
Potts–Villforth outputs remain `SEARCH_STAGE`; staged confirmation rows remain
`CONFIRMATION_PROTOCOL`.

For each `(pair stratum, rung, H, criterion)` report distinct-pair counts in this order:

1. eligible for the physical pair-consistent intervention;
2. both epoch transforms/operator gates complete;
3. both required fits or pixel-level source measurements complete;
4. complete auxiliary protocol inputs (for example MacLeod visual adjudication);
5. classifiable as CL or non-CL;
6. unclassifiable, split by operator, fit, uncertainty-calibration, measurement, and
   auxiliary-protocol reason.

The classification fraction denominator is all eligible distinct pairs, never rows,
realizations, fit survivors, or search-stage candidates. No realizations are currently part
of Q2; if later authorized, realization counts still never inflate object/pair denominators.

## J082 boundary

J082's corrected broad-Hβ point estimate is retained. Its unsupported DESI Hβ-region
uncertainty calibration remains an explicit criterion-support gap. Consequently it is
unclassifiable for MacLeod/Green and Guo `Max(N_sigma)` wherever corrected pixel variance is
required; it is not counted as non-CL and is not repaired by native IVAR. Criteria not using
that unsupported uncertainty quantity retain their separately established support status.

No spectra, fits, classifications, weights, or probabilities were generated by this design.
